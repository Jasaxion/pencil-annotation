# Pencil 手写批注 / Pencil Annotation

在思源笔记文档上手写批注的插件：用 **Apple Pencil / Android 手写笔 / 数位板**在正文上书写、标记和移动笔迹。笔迹保存在工作空间的插件私有目录；同一 Docker 实例的多个浏览器共享数据，独立工作空间则依赖思源同步。

> 这是 Jasaxion 自用维护的个性化分支，基于 [BUGdefender404/pencil-annotation](https://github.com/BUGdefender404/pencil-annotation)。请用本仓库的构建包更新，避免官方集市更新覆盖定制功能。0.3.0 引入新的同步存储，升级前备份整个插件数据目录，并刷新所有编辑中的浏览器/PWA。

> 上游项目的灵感来自 [Cherise233/siyuan-document_drawing-plugins](https://github.com/Cherise233/siyuan-document_drawing-plugins)。本分支沿用 BUGdefender404 的 MIT 实现，并重点改进浏览器手写、跨设备定位、同步可靠性与导出。

## 功能

- **压感钢笔**：基于 Pointer Events 读取触控笔压感，支持 Android 手写笔和 Apple Pencil（取决于设备/浏览器上报能力）；鼠标绘制默认关闭，开启后使用固定粗细。
- **荧光笔**：半透明、`multiply` 混合，标记文字时文字依然清晰可见，重叠处自然加深（单笔内部不会出现交叠深点）。
- **橡皮擦**：整笔擦除（笔画级），拖动即擦，可选大小，带光标圈。
- **选择**：点选笔迹后可整体拖动、复制、删除。
- **撤销 / 重做**：工具栏按钮（桌面端另有 `Ctrl+Z` / `Ctrl+Shift+Z`），最多 100 步。
- **输入分离（手写优先）**：手写模式下笔负责绘制、手指只翻页（含表格横向滚动），鼠标绘制默认关闭，真鼠标仍可编辑正文。笔正在书写时屏蔽掌触；触摸勾选任务、拖表格或编辑文字前先退出手写模式。退出后恢复普通笔/触摸操作。思源 3.8 的表格增删/拖动与块侧边控件也隔离笔接触和笔右键，不改变普通鼠标操作。
- **笔尖双击**：在页面上快速点两下，切换钢笔 ↔ 橡皮擦。默认关闭，避免点号/短笔画被误识别；已有用户的明确设置保留，可自行关闭。不是笔身双击手势。
- **浮动工具栏**：可拖动的工具球 + 展开面板，位置记忆；设置可隐藏工具球，桌面顶栏/命令仍可切换手写。手机、平板可从插件设置重新显示工具球；小屏工具栏自动分行。
- **导出**：完整正文与手写合成为图片型 PDF，生成后通过浏览器下载；另保留笔迹 PNG 保存/插入，并可下载包含未保存修改的原始 JSON 备份。
- **中英双语界面**。

## 数据存储与多设备同步

0.3.0 的数据仍位于插件私有目录，但不再让多个浏览器覆盖同一个 JSON：

```text
{工作空间}/data/storage/petal/pencil-annotation/
  {文档ID}.json                         # 旧文件，不覆盖；文档明确删除后清理
  sync-v2/{文档ID}/
    base-{内容哈希}.json                # 确定性的旧数据迁移备份
    w{独立写入会话}-{序号}.json         # 不可变的累计版本快照
    retired-v1.json                     # 删除后保留的旧客户端屏障，无笔迹
    g{代次}/...                        # 文档恢复后，新笔迹使用独立代次
  document-lifecycle/{文档ID}/
    deleted-{代次}.json                 # 已确认删除的代次边界，无笔迹
    active-{代次}.json                  # 恢复后新代次已启用，无笔迹
```

- 锚定笔迹改为**块相对坐标**；旧的绝对坐标按记录的创建原点迁移，不依赖当前设备排版猜测。无锚点旧笔迹仍保留文档坐标。
- 新增、移动、删除均按已观察到的笔迹版本处理。并发修改同一笔时，冲突版本直接并列显示，可分别移动或删除；同时发生删除和修改时保留修改副本，避免静默丢笔。
- 分屏共享状态；独立页面使用不同写入身份。保存采用 1.2 秒防抖，并在页面可见时每 5 秒检查新快照。迁移后的普通轮询只下载新命名的快照，不反复下载旧笔迹文件。
- 每个写入会话保留最新两个已验证的累计快照，只清理本会话的更早快照，不自动清理其他会话或过期删除记录。删除记录及已保存笔迹的删除前数据会保留，**视觉删除不等于安全擦除**。
- 远端改动涉及的笔迹会使相关旧撤销记录失效，防止撤销覆盖别的设备更新；不相关笔迹仍可撤销。

### 删除文档

- 收到思源成功的文档删除通知后，清理该文档及通知中包含的子文档的旧笔迹文件、迁移备份和旧代次快照，并停止旧页面的晚到写入。**恢复单篇文档不会恢复已清理的笔迹**；新手写进入新代次。
- 普通删除自动处理。思源 3.8.6 的删除通知没有唯一事件号；文档曾恢复、笔记本关闭/锁定或无法排除通知歧义时，保留数据并请求确认。取消不会清理待确认的代次；仅凭关闭、锁定、网络失败或查不到文档不会触发删除。
- 保留少量只含文档 ID/代次的删除标记，防止旧数据复活，**不要手动删这些标记**。同步晚到的旧文件会在插件运行期间逐步清理，不清理恢复后的新代次。
- 插件未运行或断网错过删除通知时，不能可靠补认删除。清理失败请保持页面，重新连接或切回页面后重试并在需要时确认。此功能清理的是当前插件数据目录，不擦除思源历史、云端/系统备份、已下载的 PDF/JSON 副本。

### 升级与恢复

1. 先备份整个 `data/storage/petal/pencil-annotation/`，安装本次 0.3.0 构建并重启思源、刷新所有浏览器/PWA；即使显示的版本号相同，也需要刷新以更换已缓存的脚本。
2. 旧版不会读取新协议中的后续变化，**不要混用旧版编辑**，也不要仅替换回旧脚本作为回退。
3. 如果旧页面继续改写旧 JSON，新版会暂停编辑/保存并显示「同步暂停」。刷新旧页面后，可从导出窗口确认「合并旧版遗留笔迹」：只追加新增或变化内容，不根据旧文件缺少某笔就删除新版笔迹；原文件不覆盖，冲突继续保留。已经永久删除的文档旧代次不能通过此入口重新导入。
4. 遇到容量或完整性错误，保持页面打开。可撤销尚未发送的修改，或在导出窗口下载 JSON 备份；该备份包含当前已加载状态与本页未保存修改，不保证包含尚未加载的远端内容。初次加载失败时应先备份服务器上的完整数据目录。

单文件、文档总量、写入会话数和历史删除标记设有安全上限（见 `src/engine/sync.ts` 和 `src/plugin/api.ts`）。达到上限会暂停而不是截断数据；长期大量会话需要受控维护，不要直接删除迁移备份、最新快照或删除标记。

> 保存成功表示本地思源内核已确认并读回验证，不代表已传到所有独立工作空间。网络失败会保留未保存状态并有限重试；浏览器强杀、断电和离线关闭仍可能丢失未确认的数据。

## 完整 PDF 导出

- 使用内核完整预览及源块清单，包含折叠、未加载到当前编辑器的正文，不退化为当前视口截图。SQL 查询嵌入和块引用按思源导出设置静态展开，结果仍受查询/导出设置上限影响；空响应不等于已确认零结果。
- **「尽量导出」默认开启**：不支持的数据库、动态图表、媒体等采用文本兼容表示或占位；无法确认的源块、转换和降级均写入 PDF 内说明及对话框提示。关闭后为严格模式，不可验证的内容会终止导出。
- 能可靠对应的笔迹按导出块原点叠加。无法可靠定位的笔迹单独放入带标注的缩略附录，原笔记不变。**含 SQL 嵌入的文档，其旧笔迹只有块 ID、没有历史嵌入实例标识，本次会保守地全部放入附录**，避免把旧查询结果上的笔迹错贴到正文。附录有预览上限，完整数据请保留笔记或 JSON 备份。
- 按当前正文宽度和字体排版，输出固定 A4 的**图片型 PDF**，正文不是可搜索/选择的文本层。安全/访问验证、准备期间源文档变化、最终页面解码失败和页数/像素/体积限制不会因尽量导出而绕过。
- 一次一个导出任务，可取消；关闭时释放资源，逐页释放画布。兼容说明置于正文及有效笔迹之后，不覆盖正文下方手写。
- PDF 模块 `pdf.js` 按需加载，在浏览器生成并下载，**不上传生成的 PDF 到服务端**；思源内核仍可能准备或缓存正文引用的资源。另有 PNG 保存到附件的入口，与 PDF 下载不同。
- 本次在隔离的本地思源 **3.8.6** 完成 Chromium / WebKit 宿主验证，包含 SQL/引用、末页笔迹及下载后服务端 PDF 文件集合不变。未启动 Docker 容器，也未执行跨工作空间云同步实测。

## 安装（开发版）

1. 本仓库构建：`npm install && npm run build`，产物在 `build/`；
2. 把 `build/` 里的所有文件复制到 `{思源工作空间}/data/plugins/pencil-annotation/`，或：
   ```bash
   node scripts/copy-assets.mjs "C:\path\to\你的工作空间\data\plugins"
   ```
3. 重启思源（或「设置 → 集市 → 重载」），在「设置 → 集市 → 已下载」中启用 **Pencil 手写批注**。

### Docker、Android 平板/手机与浏览器 PWA

插件声明支持 `docker` 后端以及桌面/移动浏览器前端。Docker 下将构建产物放到**容器实际工作空间**的 `data/plugins/pencil-annotation/`，并持久化挂载整个工作空间、确保可写。绘图在浏览器端进行，容器无需接入手写笔或安装 Node.js。

Android 平板、支持手写笔的手机及浏览器 PWA 使用同一套输入处理；笔须被浏览器识别为 `pointerType="pen"` 才有真实压感。若数位板驱动只上报 `mouse`，浏览器无法把它与真鼠标区分：优先启用驱动的笔/压感模式（Windows 下检查 Windows Ink），或开启「鼠标绘制」作为兼容方案。报告问题时请注明系统、浏览器版本、笔型号和是否使用 PWA。

### 在 iPad 上使用

推荐用 Safari/PWA 访问部署了本分支的思源服务。官方集市提供的是上游版本，不是这里的个人版，不要用其更新覆盖本分支。

iOS App 的工作空间位于应用沙箱中；若使用原生 App，需要采用思源支持的插件安装/同步方式，并确保所有编辑端升级到相同协议版本。

## 发布流程（维护者）

1. 同步更新 `plugin.json`、`package.json`、锁文件和 `CHANGELOG.md` 的版本；
2. 运行类型检查、回归与宿主测试，再执行 `npm run pack`；
3. 自用安装时解压新的 `package.zip`，复制全部产物（包括 `pdf.js`），重载插件并刷新浏览器/PWA；
4. 是否提交、推送、打标签或创建 Release 由维护者决定；本分支不自动发布到官方集市。

## 使用

- 点击顶栏按钮（桌面）或屏幕上的**笔形工具球**（全平台）进入/退出手写模式；
- 手写模式下：透明画布仅显示笔迹；在浏览器/思源的触摸转鼠标逻辑之前接管绘图与触摸事件。手指移动按动画帧翻页并提供有限惯性，不触发正文编辑；鼠标仍可正常编辑（除非开启鼠标绘制）；
- 工具栏从左到右：钢笔 / 荧光笔 / 橡皮擦 / 选择 · 颜色与粗细 · 撤销 / 重做 / 导出 / 清空 · 设置 / 收起；
- 选中笔迹后工具栏会出现 复制 / 删除 / 完成 三个操作按钮；
- 「清空」有确认弹窗，且清空本身可撤销。

## 开发

```bash
npm install
npm run typecheck   # 类型检查
npm run build       # 构建 index.js + 按需加载的 pdf.js，再拷贝静态资源
npm run deploy -- "工作空间/data/plugins 的路径"   # 部署已有 build/，请先构建
npm run harness     # 打开浏览器测试台 http://localhost:5199/test/harness.html
npx playwright install chromium webkit
npm test            # Chromium / WebKit 回归，可用 BROWSER=chromium 只跑一个引擎
# 可选：启动隔离的临时工作空间，验证真实思源内核与浏览器前端
SIYUAN_KERNEL=/path/to/SiYuan-Kernel npm run test:host
npm run pack        # 构建 + 生成 package.zip（上架用）
```

`test/sync.mjs` 验证迁移与并发状态；`test/deletion.mjs` 验证明确删除、晚到写入、恢复代次、迟到确认及加载竞态；`test/regression.mjs` 保留输入与存储回归；`test/pdf.mjs` 验证分页像素、静态嵌入、兼容附录和失败清理。`test:host` 使用临时工作空间验证真实思源多浏览器并发、表格控件笔/鼠标隔离、完整 PDF、SQL/引用及 PDF 不上传/不在工作空间落盘，还有父子文档删除、真实历史恢复和确认/取消清理；不读取或修改已有笔记。

自动化浏览器及移动视口模拟**不等同于 Android/iPad 真机或已安装 PWA 验证**。真实压感、系统防误触和系统打断仍需对应设备复验；WebKit 自动化的笔事件为合成事件。

## 目录结构

```
src/
  engine/       # 绘图、块相对坐标、版本集合/删除标记、撤销
  overlay/      # 稳定的输入隔离、绘制及浮动工具栏
  plugin/       # 内核存储、PNG、完整 PDF 与导出对话框
  index.ts      # 插件入口：生命周期 / 事件总线 / 保存调度 / 设置面板
```

## 已知限制（v1 路线图）

- 笔迹使用 CSS 像素坐标，可随锚定的文字块平移，但并非字符级绑定：屏幕像素密度本身不是问题；电脑/平板/手机排版宽度、字号或换行不同后，圈线不保证仍精确贴合文字。精确标记文字请使用思源原生文字高亮；
- 无图层、无套索多选、无像素级橡皮（计划后续版本）；
- 撤销历史仅保存在当前会话内存中，关闭文档后清零（笔迹本身已持久化）；
- 长文档采用视口画布 + 可视区裁剪渲染，笔迹数以千计时滚动重绘可能需要进一步的瓦片缓存优化。
